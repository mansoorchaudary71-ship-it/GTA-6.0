1) On GitHub, DELETE .github/workflows/main.yml (it is EMPTY - that causes "No event triggers defined in on").
   Open the file > click the 3 dots (top right) > Delete file > Commit.

   Add file > Create new file > name: .github/workflows/pages.yml > paste pages.yml-copy-paste.txt > Commit).
3) Actions tab > Deploy to GitHub Pages > Run workflow. Green tick > Settings > Pages > Visit site.
